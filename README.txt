ERP Kajoe Manis - Demo Manufacturing Order

Struktur:
ERP_Kajoemanis/
  html/index.html
  css/style.css
  js/app.js

Cara menjalankan:
1. Ekstrak folder ERP_Kajoemanis.
2. Buka html/index.html di browser (Chrome/Edge).
3. Pilih produk dan jumlah untuk melihat estimasi kebutuhan bahan dari resep.
4. Simpan MO, lalu ubah status melalui tombol aksi.

Catatan:
- Data tersimpan di localStorage browser, bukan database/server.
- Resep dan kuantitas mengikuti PDF tugas yang diberikan.
- Ini prototype front-end untuk tugas fitur Manufacturing Order, belum mencakup autentikasi, stok bahan real-time, modul penjualan penuh, atau backend.
